🪵 裸弓 Barebow

無瞄具・無穩定桿・本能瞄準

規則限制

  • 結構與反曲弓相同，現代材質均可

弦行技術（String Walking）

射手根據與靶的距離，調整手指在弦上的位置：

  • 靶較遠　手指靠上（接近箭矢）
  • 靶較近　手指靠下（最多 20 cm）

靠手指數弦線圈數定位，對一致性要求極高。

🎽 技術 / 前半段

建立期（步驟 1–5） Setup Phase

1 — 站姿 Stance

  • 腳與肩同寬，側身對靶
  • 重心均勻分布於兩腳
  • 膝蓋輕微彎曲，不鎖死

2 — 搭箭 Nocking

  • 將箭搭扣入弓弦的搭箭點
  • 羽翼方向需正確朝外

3 — 勾弦與握弓

  • 以三指勾弦（地中海式）
  • 握弓輕鬆，避免緊握造成偏斜

4 — 預備姿勢 Set Position

  • 肩膀放低，啟動背部肌群
  • 建立一致的骨骼對齊
  • 心理預備：進入專注狀態

5 — 開弓 Draw

  • 以背部肌群（非手臂）帶動開弓
  • 肩胛骨向脊椎靠攏
  • 弓手肘微轉避免弓弦碰觸

💡 前半段的核心是骨骼對齊與肌群啟動， 為後半段的穩定放箭奠定基礎。

🎽 技術 / 後半段

執行期（步驟 6–9） Release Phase

6 — 定錨 Anchoring

  • 拉弓手固定於臉部特定位置
  • 反曲弓：中指放嘴角
  • 複合弓：掌根貼臉頰
  • 一致性是定錨的核心要求

7 — 瞄準 Aiming

  • 反曲弓：覘孔→瞄具針→靶心對齊
  • 複合弓：放大鏡+針式或光纖
  • 裸弓：箭尖對準目標（本能）

8 — 放箭 Release

  • 放鬆手指，讓弦自然滑出
  • 非主動打開手，而是被動鬆開
  • 放箭瞬間背部繼續用力

9 — 跟進 Follow-through

  • 放箭後維持身體姿勢
  • 直到箭落靶才能放鬆
  • 反映放箭品質的指標動作

💡 後半段的核心是放箭的一致性， 任何細微的肌肉張力變化都會影響落點。

🎽 技術 / 物理概念

🌀 射手悖論 Archer's Paradox

現象說明

放箭時，弓弦向前加速推動箭的後端， 但箭鏃因慣性相對緩慢。

後段快於前段 → 箭矢在離弦瞬間彎曲， 繞過弓把 → 在飛行中因彈性振盪回正。

震盪方向

弓種震盪方向原因
反曲弓水平手指左右放弦
複合弓垂直放箭器垂直脫弦
裸弓水平同反曲弓

脊值（Spine）的關係

  • 脊值太軟　彎曲過大，飛行不穩，偏靶
  • 脊值太硬　幾乎不彎，同樣影響軌跡
  • 脊值正確　適當彎曲後完整回正，穩定飛行

調箭實際應用

  • 選擇正確箭矢脊值（依弓磅數）
  • 調整壓力鈕彈力（反曲/裸弓）
  • 設定箭座位置
  • 紙張穿透測試（Paper Tuning）

🏆 競技項目 / 其他三種

3D射箭・飛行射箭・越野射箭

🦌
3D 射箭
3D Archery
  • 在自然/人工地形射擊立體動物造型靶（泡綿製）
  • 距離通常未標記，考驗距離判斷
  • 常用：本能弓、長弓
  • 強調實戰模擬感
🚀
飛行射箭
Flight Archery
  • 比的是箭矢飛行距離
  • 無靶面，純比誰射得最遠
  • 依弓種與磅數分組
  • 最考驗弓具效能與箭矢設計
⛷️🏃
越野 & 滑雪射箭
Run & Ski Archery
  • 越野射箭：跑步 + 射箭（夏季）
  • 滑雪射箭：越野滑雪 + 射箭（冬季）
  • 類似冬季兩項（Biathlon）概念
  • 考驗體能消耗後的射箭穩定度
💡 共同精神：這三種項目都跳脫了「站在固定距離射固定圓靶」的框架，各自強調距離判斷、器材效能或體能整合能力。
